# Figmaデザインカンプ画像

このフォルダには、Laravel在庫管理Webアプリ「Nexte」のFigmaデザインカンプ画像を保存しています。

## 画像一覧

### ダッシュボード

* `dashboard_01_top.png`
  ダッシュボード画面上部。サイドバー、ヘッダー、状態別サマリーカードを含みます。

* `dashboard_02_bottom.png`
  ダッシュボード画面下部。「今日確認すべき商品」の商品カード一覧を含みます。

### 在庫確認リスト

* `inventory_list_01.png`
  在庫確認リスト画面上部。検索欄、フィルター、一覧テーブル上部を含みます。

* `inventory_list_02.png`
  在庫確認リスト画面下部。一覧テーブルの続き、操作ボタンなどを含みます。

### 在庫詳細・編集

* `inventory_edit_01.png`
  在庫詳細・編集画面。商品情報、在庫状態、編集フォームを含みます。

### 商品管理

* `product_manage_01.png`
  商品管理画面。商品一覧、検索欄、新規登録ボタンを含みます。

* `product_form_01.png`
  商品登録・編集フォーム画面を含みます。

### 店舗管理

* `store_manage_01.png`
  店舗管理画面。店舗一覧、検索欄、新規登録ボタンを含みます。

* `store_form_01.png`
  店舗登録・編集フォーム画面を含みます。

## 実装方針

* 画像は見た目の参考資料として扱います。
* Figma生成コードはそのまま使用しません。
* Laravel Blade + 通常CSSで再現します。
* React、Vue、Tailwind前提にはしません。
* サイドバー、カード、テーブル、ステータスバッジ、ボタンは共通化を意識します。
* ログイン機能、ユーザー管理、設定画面、商品画像、販売価格は実装しません。
* まずはダッシュボード画面から実装し、その後に在庫確認リスト、在庫詳細・編集、商品管理、店舗管理へ進めます。
